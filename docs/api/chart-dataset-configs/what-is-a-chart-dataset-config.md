## Table of Contents

* [Overview](#overview)
* [Related Resources](#related-resources)

## Overview

A `ChartDatasetConfig` is used to map a dataset to a chart with custom parameters.

A `ChartDatasetConfig` belongs to a `Chart` and requires both a `chart_id` and a `dataset_id` when creating one.

* `chart_id`: The ID of the `Chart` where you want to add the dataset.
* `dataset_id`: The ID of the `Dataset` that you want to map to the chart.
