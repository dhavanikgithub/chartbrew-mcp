## Table of Contents

## Overview

A **chart** is a visualization of data. It is used to display data from your datasets in a visual format.

A `Chart` is composed of one or more `ChartDatasetConfigs`. Each `ChartDatasetConfig` maps a dataset to a chart using custom configuration parameters.

A `Chart` belongs to a `Dashboard` and requires a `project_id` when creating one. The `project_id` represents the ID of the `Dashboard` where you want to add the chart.
